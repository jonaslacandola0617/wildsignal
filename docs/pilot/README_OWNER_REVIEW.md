# Start here

1. Extract the complete ZIP into a NEW folder.
2. Double-click **PLAY_GAME.cmd**.
3. Walk around. All intended highlights, outlines and corrected shadows are already ON.

No other launcher or configuration is required. **R** changes480/640 without leaving the game. Normal movement, companions, combat and saves are preserved. The default is BALANCED, not BOLD; edge light is brighter and more saturated. Brown terrain/bark and original kit source artwork are preserved. The review includes native captures and one real walking preview. Windows compilation is tested; physical Windows/Intel UHD GPU execution is not tested here.
