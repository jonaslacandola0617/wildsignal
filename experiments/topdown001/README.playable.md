# TOPDOWN-001: playable Lantern Quay owner-review slice

Extends the original experiment with a real SDL3 window, a native-pixel CPU
framebuffer and editable tilemap/collision data. Original `src/main.cpp` remains
byte-for-byte unchanged and can still build as `wildsignal_topdown001` when
libpng development files are available. No first-person source or old PR changes.

The owner-selected Pixel Crawler Free Pack 2.11 is loaded privately. The public
repository/CI contain code, a semantic map and synthetic tests only. No sprite
PNG, cache or licensed screenshot belongs in public Git or CI artifacts.

## Build

Windows x64: Visual Studio 2022 Desktop C++, Git, CMake >=3.24; Python/Pillow for
offline imports only. Runtime adds no PNG decoder: native RGBA assets load once.
SDL3 uses the same immutable 3.2.10 commit as the existing engine.

```powershell
cmake -S experiments/topdown001 -B C:/private/topdown-build -G "Visual Studio 17 2022" -A x64 -T v143
cmake --build C:/private/topdown-build --config Release --parallel 2
ctest --test-dir C:/private/topdown-build -C Release --output-on-failure
python -m pip install Pillow
python experiments/topdown001/tests/import_test.py experiments/topdown001
```

Linux: configure the same project with `-DCMAKE_BUILD_TYPE=Release`; SDL3 development
platform libraries are needed for a desktop window. A headless console-only build
can use `-DSDL_UNIX_CONSOLE_BUILD=ON -DSDL_X11=OFF -DSDL_WAYLAND=OFF` and
`SDL_VIDEODRIVER=dummy` for actual SDL lifecycle/input/readback tests; this is not
an on-screen desktop or target-device performance test. `-DTOPDOWN001_BUILD_SDL=OFF`
builds the deterministic CPU route independently. `-DTOPDOWN001_SANITIZE=ON`
enables address/undefined behavior sanitizers with supported GCC/Clang toolchains.
The new renderer uses the existing bounded JSON parser without altering it.

## Private import and play

Obtain the exact source ZIP from the authorized private repository and the
visually reviewed PRIVATE crop/animation catalog delivered with this review.
The handoff records the original ZIP identity. Its Terms.txt allows functional
commercial use and edits, optional attribution, and prohibits unapproved
standalone art sale/marketing. Keep raw sheets/master ZIP and the catalog private.
No artwork is generated by this tool or automatically downloaded by the game.

```powershell
python experiments/topdown001/tools/import_assets.py C:/private/original.zip C:/private/catalog.json C:/private/new-pack
C:/private/topdown-build/Release/wildsignal_topdown001_playable.exe --assets C:/private/new-pack/pack.json --map experiments/topdown001/data/lantern_quay.json --output C:/private/runs/unique
```

WASD/arrows move; diagonals normalize speed. Four directional idle/walk clips use
actual source frames, mirroring the inspected side clip for left. ESC exits.
F1 toggles 1x/2x world zoom (320x180 framebuffer stays fixed), F2 toggles crisp
camera/FPS/CPU/RSS debug HUD, F12 saves actual displayed BMP. Window is resizable;
nearest integer upscale and letterboxing apply whenever output size permits.
Use `--debug` for initial HUD. Focus loss clears held keys and pauses simulation.
Start controls and the temporary companion are prototype-only; no battle/online
systems, interactions, inventory or production creature integration were added.

The player uses the supplied **Body_A base-body template**, not a finished avatar.
The companion uses the free pack Orc idle/run actor as an explicitly temporary
follower; it is not a canonical WILDSIGNAL creature and never loads creature masters.
Only the player has authored up/down clips; the test follower has a side animation
mirrored for left while moving up/down too. No directional art was invented.

## Scene/renderer contract

`data/lantern_quay.json` has separate ground and collision rows, named ground
aliases, explicit world-pixel object feet/anchors and native source-size sprites.
The tiny map is deliberately composed: cottage, stepped native roof pieces,
shuttered windows, grass-fringed path, flowers, trees and a fenced stone quay.
No tile selection uses the old proof's arbitrary modulo coordinates. Asset crop
coordinates and provenance stay in the PRIVATE reviewed catalog/manifest.

Layer 0 objects are ground decals. Layer 1 objects and actors sort by explicit
foot Y, with deterministic tie order. Building pieces share one front anchor;
trees use canopy-sized images and a separate small trunk collision cell. Large
sprites are not assumed to be 16x16. Source straight alpha is preserved and
composited using the original experiment's integer blend. Collision uses a foot
box with two-pixel substeps; diagonal movement cannot tunnel through tiles.

Player speed is 64 native pixels/s, collision radius 4px. Follower speed is 76px/s,
stops about 24px behind when line of sight is clear, and takes a bounded four-way
BFS route around obstacles. It never teleports. The CPU simulation/render path avoids
hot allocations in the audit; assets are capped at 12 MiB, map at 4096 cells and scenery at
512 entries. Camera eases at 9/s with a 50px upward look-ahead; render position
is rounded to integer world pixels. No subpixel blur or per-frame PNG decoding.

The source-map PNG metadata inherited from the old proof does not match the
verified original ZIP's encoded PNGs; the named tree sheet is actually 256x128.
This implementation validates actual archive entries and captures those exact
native pixels; it does not treat old encoded-file hashes as verified raw sources.
The original proof/source-map file is retained for historical comparison.

## Deterministic evidence and measurements

```powershell
wildsignal_topdown001_headless.exe --headless --assets C:/private/pack/pack.json --map data/lantern_quay.json --demo --frames 480 --capture-every 4 --sequence C:/private/new-sequence --capture C:/private/final.ppm --output C:/private/new-run
```

This runs 480 contiguous 60Hz simulation frames (8 simulated seconds), captures
120 actual framebuffer PPMs, and exercises all four directions, camera motion
and following. PNG conversion/animation assembly is a separate lossless offline
step; do not label generated drawings as engine output. Use a fresh output prefix
and sequence directory. `--frames 1 --capture ...` captures spawn; saved frames
and CSV give additional camera views. `--zoom 2` tests native-pixel doubling.

JSON reports CPU median/P95, process peak RSS and art pixel bytes. CSV retains
per-frame render/work time, elapsed loop time, actor positions, animation index,
camera and zoom. CPU timing excludes screenshots, CSV, SDL upload/present and cap;
use full elapsed-loop data for display/pacing analysis. Memory uses Linux /proc
or Windows working set; Android PSS and hardware thermal behavior are unmeasured.
`--smoke-test --frames 180 --fps 0` injects real SDL keyboard/focus/resize events
using synthetic CI art; it is not a human playtest.

## Review boundary

No doors open, no interior, dialogue, combat, bonding, progression, multiplayer or
online integration. The water is a native static tile, not an animated/simulated
sea. Props/house are assembled source sprites. Collision is authored tile masks,
not a general physics engine; roofs/canopies rely on foot sorting, not elevation.
Keep Windows 11 i3/4GB, Windows 7 and Android performance/compatibility NOT RUN
until those devices are measured. Owner must judge readability, cute-fantasy
feeling, 16px scale, camera/movement and companion visibility from actual stills
and contiguous motion before further development.
