# Dense grass LOD, large color regions and full-effects review

The owner requested performance improvements, large organic grass/terrain color patches covering50% light green/30% standard green/20% teal, and the complete existing sunlight/atmosphere presentation enabled. This branch preserves the playable systems and previous source assets.

The existing instanced mesh path supports two optional derived `lod_paths` and `lod_distances` for the single R2 grass family. Source meshes remain unchanged. Derived mesh LODs keep all106 leaves and original outer-boundary/tip positions while removing interior cross-section subdivisions. Full/medium/far contain3328/1664/832triangles. Bands use3m/7m thresholds with deterministic staggering and0.35m hysteresis. There is no billboard replacement or blanket density reduction. L toggles LOD for comparison; HIGH still uses the same8844 placements and original clearances.

Optional `meadow_patches` loads bounded numeric WSP1 regional weights, shared by terrain and grass in world XZ. It is control data, not diffuse artwork. The private generation step measures area against the original visible green terrain surface, then solves the requested50/30/20 proportions. The shader applies a common regional hue and restrained original value detail, instead of varying green families within each clump. Original brown texels and non-ground materials bypass terrain recoloring. Earlier manifests without patches/LOD retain their previous behavior with matching effect controls. P toggles patches for inspection.

One **PLAY_GAME.cmd** starts dense HIGH grass, BALANCED toon/edges, clean shadows, depth-aware shadow-map volumetric shafts and haze ON. The inherited medium atmospheric approximation uses quarter-size buffers and8steps; no new heavy lighting system is added. Grass casts no shadows. R changes480/640; G changes density; V/H/O compare shafts/haze/shadows in the same executable. No automatic quality changes hide the requested effects.

Telemetry appends actual resolution, density, LOD populations, patch/effect/source-mode settings and atmospheric quality to each frame, preserving previous column names. This avoids inferring mixed manual test settings from aggregate run logs.
