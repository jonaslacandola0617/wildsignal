# Shaped rays and three readable greens

Owner request: visibly separated diagonal soft-edged shafts, plain-color grass material, no grass outlines, retained grass edge highlights, and#a3e635 only under concentrated beam light/#65a30d normal light/#1a2e05 shadow.

This is an **art-directed focused-sunlight rig**, not a claim that the sparse existing canopy naturally creates the supplied reference. The private manifest adds up to4 numeric soft elliptical sunlight apertures. A single GLSL `beamField(worldPosition)` projects along the real sun direction onto a fixed worldY0 plane; all grass, green terrain and ray-integrated air use exactly that field. Real shadow-map visibility blocks it, and ray integration stops before visible geometry. Beams have a broad body and continuous feather; no ray cards, rectangles, replacement textures or meshes are generated. Same field illuminates the real terrain height, so its footprint is not a camera-following screen overlay.

The new response reserves light green for aperture cores with direct illumination, retains normal green outside them and uses deep forest green for object shadows. It does not enforce50/30/20 spatial ratios. Grass ignores source texture/vertex/instance color variation **only in the new material response**; original assets stay unchanged and are visible in the original comparison. Green terrain preserves restrained source value detail; brown texels/non-ground assets bypass the ramp. Highlights, haze and air scattering can modify final display pixels beyond these palette anchors. The renderer has a directional sun and ambient fill; no new local point lights or gameplay are introduced.

ONE PLAY_GAME.cmd starts new BEAM response, grass outlines OFF, highlights ON, shadows/shafts/haze ON, HIGH grass and preserved LOD. U cycles BEAM→REGIONAL→SUN→BEAM; I toggles only grass outlines; J/K remain global highlights/outlines; V shafts, H haze, O shadows; B LOD; L quality; R480/640; G density. Existing WASD/mouse/E/combat/F5/F9 controls unchanged.

`--meadow-response beam|sun|regional` preserves the preceding sunlight and earlier regional modes; `--grass-outlines off|on` is independent of highlights. `--diagnostic beam` shows aperture/visibility/visible-beam in RGB. Invalid aperture count, dimensions, center/radius bounds and palette values fail closed. Packs without apertures fall back to prior sunlight behavior. `--meadow-lighting off` retains its earlier regional override. Source/toon F bypasses the new response and beam volumes.

For readable low-resolution shafts, BEAM medium uses half-size atmosphere and12three-point steps; LOW uses quarter-size/8steps; HIGH half-size/16steps. Max ray distance32m, soft vertical fade10–16m. Other modes retain quarter-size/8medium and prior soft/defined profiles. All material/normal buffers stay sharp. This increases atmosphere work; no Intel UHD performance guarantee or automatic hidden quality reduction is made. The effects remain independently switchable. CSV appends actual response, grass-outline state and aperture count, preserving prior fields.
