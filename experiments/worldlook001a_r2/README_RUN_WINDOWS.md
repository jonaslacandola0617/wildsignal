# Small plot Windows x64 review

Unzip the complete PRIVATE review package to a writable folder. Run PLOT_M1.bat
or PLOT_M2.bat; Windows11 x64/OpenGL3.3 driver required. Keep assets/mesh beside EXE.
B0 additionally uses unchanged private assets/grass/grass_kit.json. CI code-only
artifact deliberately has no art: obtain the separate private art package first.
No installation/admin rights needed. This is unsigned experimental software;
no Windows graphics/Intel UHD/Android/Win7 compatibility claim until actual tests.

Click window to mouse-look; WASD, Esc unlock/exit. Grass stays fixed in world.
Camera follows plot height. F1 switches480/640/960 (480 primary); F3 changes pose;
F12 saves actual PPM screenshot. Each launch creates its own run directory.
Motion routes run real first-person camera paths, not an edited model turntable.

COMPARE.bat creates matched native PPM stills (no FPS claim).
WALK_M1.bat / WALK_M2.bat capture15-second scheduled450-frame routes at30cap;
actual timing may exceed15seconds on slow hardware. All raw timing is retained.
RUN_INTEL_UHD_BENCH.bat runs capture-free cost and precise30/60cap comparisons.
ZIP runs/ and return it privately. Do not upload artwork/captures to public issues.
Hardware results remain NOT RUN until owner executes these launchers.
