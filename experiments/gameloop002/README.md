# GAMELOOP-002 / WORLDSTYLE-001 owner review

Stacked from GAMELOOP001 commit6830afe on the existing PR50 branch. Old experiments are unmodified. This isolated target keeps the confirmed battle/recruitment/save rules and adds movement-trail following, bounded local routing/waiting, continuous-near grass distribution and reversible private material variants.

Build with `cmake -S experiments/gameloop002 -B build/game2`, then `cmake --build build/game2 --parallel 2` and `ctest --test-dir build/game2 --output-on-failure`. On Windows use VS2022 `-A x64`, build `--config Release`, CTest `-C Release`. Private runtime assets are required to play; optional `-DGAMELOOP_ASSETS=<absolute-private-runtime> -DPIXEL3D_TEST_GL=ON` enables actual private mesh/input/GL tests. Source-only CI never substitutes for Windows GPU testing.

Extract the private portable ZIP and launch PLAY_GAME.cmd. Controls and save schema are unchanged: WASD/mouse/E,1/2/3 combat, Enter return/resume, F5/F9 save/load, G density, R resolution, Esc pause and Q save/quit while paused. F3 displays follower states. Idle or WAIT intentionally keeps position while genuine Idle animation continues; obstruction is not permission to fly through a rock or gain height.

Comparison controls: `--followers trail|legacy`, `--grass-layout continuous|legacy`, `--worldstyle source|pixel`, `--render-mode original|toon`, `--texture-budget native|256`. Defaults are trail/continuous/pixel. Legacy following deliberately reproduces the old yaw chase for diagnosis only. Preserve identical poses/routes when comparing. `--coverage meadow|nearmeadow|geometry|combined` creates diagnostics; nearmeadow limits the designated-ground denominator to5m planar distance. Ordinary painted green is never geometry. `--debug-follow` / F3 exposes states; CSV records both actors, target, plan count, velocity and camera yaw.

The192-point translation-only trail is bounded; follower targets lag traveled distance, independently of camera heading. A maximum66-node clearance-expanded visibility graph provides persistent routes around existing solids. Replanning is bounded, waiting cooldown1.5s, arrival hysteresis, speed2.5m/s and steering acceleration6m/s². Safety stops at an obstruction can stop immediately; no teleport or artificial altitude is used. Two actors reserve separation and can wait rather than force a narrow passage. Dynamic crowds/general navigation and animation cross-fading are outside this fix; actual source Idle/Fly/Attack clips are preserved.

Grass reuses all six unchanged R4/R5 mesh variants, the70/30 mix and original scale. A fixed denser root field is selected by distance/density; farther geometry retains LOD/culling and ground fallback. Low stays close to the old budget; medium/high prioritize nearby coverage. Paths, rock bases, house entrance and encounter clearing retain the same exclusions. Grass shadows, wind and volumetric sunlight remain OFF.

WORLDSTYLE maps are authored privately as editable SVG pixel clusters, not shrunk source maps. The existing texture-style table selects them without changing UVs/geometry/collision. GL_SRGB8_ALPHA8 albedo is decoded to linear before lighting; display gamma remains unchanged. Style uses nearest magnification and nearest mip selection for distance stability; baseline keeps its base-level sampling. Only mapped materials receive the adjusted three-tone lighting, with all sun/camera/scene parameters unchanged. An atlas/material pass cannot remove a detailed mesh silhouette; owner approval remains open.

Issue49 records the owner's physical Windows GAMELOOP001 test and IntelUHD i5-12450H/8GB results. They are prior-build owner evidence, not measurements of this revision or certification for i3/4GB. Pacing is preserved. New Windows gameplay/Intel/Android/Win7 validation must be labelled separately.
